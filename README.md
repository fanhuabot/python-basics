## 目录结构

```
f1/
├── week01/          # 第 1 周：环境与基础语法
│   └── hello.py
├── week02/          # 第 2 周：容器与函数
├── ...
└── README.md
```

每周一个目录，目录里放当周的练习脚本和一份 `notes.md`（当天卡住的问题写在这里，比记在脑子里可靠）。

## 怎么运行

需要 Python 3.11 以上：

```bash
python week01/hello.py
```
